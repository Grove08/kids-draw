# Рисовалка

Детская рисовалка (PWA) для iPhone и iPad: кисть, ластик, цвета, толщина, штампы-зверушки,
отмена, галерея с автосохранением. Работает без интернета.

## Установка на iPhone / iPad
1. Откройте ссылку на приложение в **Safari**.
2. Нажмите «Поделиться» → **«На экран "Домой"»**.
3. Запускайте с иконки на домашнем экране (так данные хранятся надёжнее).

## Для родителей
- Рисунок сохраняется сам. Домик 🏠 открывает галерею.
- В галерее **удерживайте шестерёнку ⚙️ 2 секунды** — у каждого рисунка появятся кнопки
  «В Фото» (через меню «Поделиться») и «Удалить».

## Разработка
```
npm test                      # тесты логики (node:test)
python -m http.server 8080    # локальный сервер
```
