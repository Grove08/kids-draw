# Азбука Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить в рисовалку азбуку: лента 33 букв, озвучка голосом iOS, закрашивание буквы пальцем, мягкая проверка 70%, награда-зверушка, звёздочки выученных.

**Architecture:** Новые модули рядом с существующими, рисовалка не меняется. Чистая логика (данные букв, подсчёт закрашенной доли, прогресс, выбор голоса, маска из пикселей) вынесена в модули без DOM и тестируется `node --test`; экраны ленты и буквы — DOM-код, проверяется в браузере вручную.

**Tech Stack:** HTML/CSS/JS (ES modules), Canvas 2D, Pointer Events, Web Speech API (`speechSynthesis`), `localStorage`, `node:test`.

**Spec:** `docs/superpowers/specs/2026-10-16-alphabet-design.md` (общая основа: `2026-10-16-kids-drawing-pwa-design.md`)

## Global Constraints

- Ребёнку никакого текста: только буквы, эмодзи, картинки (текст допустим только в родительской зоне).
- Озвучка только `speechSynthesis`, язык `ru-RU`, `rate` 0.8; вызывается только из обработчиков касаний.
- Порог засчитывания: 0.7 (70% площади буквы); без «ошибок», рисование мимо буквы разрешено.
- 33 буквы, любая доступна; выученные — ⭐; выученные хранятся в `localStorage` ключ `kd-learned` (JSON-массив строк).
- Кисть на экране буквы одна: толстая (`WIDTHS.thick`), один цвет; ластика нет, есть кнопка 🧽 «сначала».
- Мультитач и ладонь — через `shouldIgnorePointer` из `drawing-logic.js`.
- Шрифт буквы: `ui-rounded`, запасной системный sans; маска строится из того же шрифта, что и показ.
- iPhone и iPad, портрет и альбом; кнопки ≥ 64 px (на планшете 72).
- Без сборки и npm-зависимостей; пути относительные; новые файлы добавляются в кэш `sw.js`, версия кэша `kids-draw-v2`.

## Review Focus

- Ребёнок рисует только мимо буквы: доля остаётся 0, `done` не наступает, ничего не падает.
- Быстрые повторные нажатия на букву: озвучки не накладываются (перед новой — `cancel`).
- Нет русского голоса или `speechSynthesis` отсутствует: касания работают, звука нет, родитель видит предупреждение.
- Повреждённый или недоступный `localStorage`: прогресс работает в памяти, приложение не падает.
- Поворот экрана на экране буквы: закрашенное сбрасывается, маска пересобирается, ⭐ сохраняются.
- Ъ, Ь, Ы без картинки и слова: экран не ломается, озвучка «твёрдый знак»/«мягкий знак»/«ы».
- «Следующая» на букве Я ведёт к ленте, а не в пустоту.

### Task 2: Подсчёт закрашенной доли и маска

**Files:**
- Create: `coverage.js`
- Test: `tests/coverage.test.js`

**Interfaces:**
- Produces:
  - `maskFromImageData(data: Uint8ClampedArray, width: number, height: number, cols: number) -> { cols: number, rows: number, cells: Uint8Array }` — `data` RGBA; клетка = блок пикселей `width/cols`; клетка закрашена (1), если альфа-канал в её центре ≥ 128; `rows = Math.round(height * cols / width)`.
  - `createCoverage(mask, threshold = 0.7) -> { addSegment(x0, y0, x1, y1, radius): void, fraction(): number, isDone(): boolean, reset(): void }` — координаты в единицах клеток сетки; `addSegment` отмечает каждую клетку маски, центр которой (cx+0.5, cy+0.5) ближе `radius` к отрезку; `fraction` = закрашенных клеток маски / клеток маски (пустая маска → 0, `isDone` → false); `isDone` ⇔ `fraction() >= threshold`.

- [ ] **Step 1: Failing tests (`coverage`):** `empty mask gives fraction 0 and is never done`; `segment through the whole mask row covers it`; `segment far outside the mask covers nothing`; `isDone flips exactly at 0.7 (mask of 10 cells, 6 covered → false, 7 → true)`; `wide brush covers cells a thin brush misses`; `repeated segments do not count a cell twice`; `reset clears coverage`. **Tests (`maskFromImageData`):** `opaque pixels become 1, transparent become 0` (RGBA массив 8×8 с непрозрачным левым полом, `cols = 4`); `rows follow the aspect ratio`.
- [ ] **Step 2:** `npm test` — FAIL.
- [ ] **Step 3:** Реализовать `coverage.js` (расстояние от точки до отрезка с зажатием проекции; клетки перебирать только в ограничивающем прямоугольнике отрезка ± `radius`).
- [ ] **Step 4:** `npm test` — PASS.
- [ ] **Step 5:** Commit `feat: coverage logic`.

**Interfaces:**
- Produces:
