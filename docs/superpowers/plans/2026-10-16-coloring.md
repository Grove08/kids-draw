# Раскраски животных Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить в рисовалку раскраски 8 зверушек: контур поверх холста, краска видна только внутри зверушки, раскраска сохраняется в галерею и открывается снова с контуром.

**Architecture:** Редактор (`canvas.js`) получает необязательный «шаблон»: мазки обрезаются по форме зверушки (`ctx.clip(Path2D)`), контур перерисовывается после каждого сегмента. Данные зверушек и пересчёт координат — отдельные модули; чистая часть тестируется `node --test`, отрисовка проверяется в браузере.

**Tech Stack:** HTML/CSS/JS (ES modules), Canvas 2D, `Path2D`, `node:test`.

**Spec:** `docs/superpowers/specs/2026-10-16-coloring-design.md`

## Global Constraints

- 8 зверушек с `id`: `cat`, `dog`, `rabbit`, `bear`, `elephant`, `lion`, `fish`, `duck` (порядок такой же).
- Координаты зверушек — SVG path data в системе 0..100 × 0..100; контур — толстая чёрная линия (1.2% от меньшей стороны холста, круглые концы), отступ от краёв 8%, пропорции сохраняются.
- Краска видна только внутри объединения `fills`; контур всегда поверх краски.
- Кнопка штампа в раскраске скрыта; цвета, 3 толщины, ластик, отмена, 🏠 — как в рисовалке.
- Поле `template` (id зверушки) в записи рисунка необязательно; неизвестный id → рисунок открывается как обычный.
- Без сборки и npm-зависимостей; пути относительные; новые файлы в кэше `sw.js`, версия `kids-draw-v3`.
- iPhone и iPad, портрет и альбом; кнопки ≥ 64 px (на планшете 72).

## Review Focus

- Ластик внутри зверушки не стирает контур; мазок поверх линии контура не закрашивает линию.
- Поворот экрана / смена размера: контур пересчитывается по новому размеру, нарисованная краска не искажается (масштабируется как у рисовалки), рисунок остаётся внутри зверушки.
- Отмена после мазка и после ластика возвращает прежнюю краску вместе с контуром (контур не исчезает и не удваивается).
- Открытие сохранённой раскраски из галереи: ограничение краски и контур восстановлены; рисунок без поля `template` по-прежнему обычный; запись с неизвестным `template` не ломает открытие.
- Мазок целиком снаружи зверушки не оставляет следов; мазок через границу закрашивает только внутреннюю часть.

### Task 2: Шаблон (пересчёт координат, клип, контур)

**Files:**
- Create: `template.js`
- Test: `tests/template.test.js`

**Interfaces:**
- Consumes: `ANIMALS`/`getAnimal` (Task 1).
- Produces:
  - `fitTransform(cssW: number, cssH: number, margin = 0.08) -> { scale: number, ox: number, oy: number }` — масштаб, при котором квадрат 0..100 вписывается в `cssW × cssH` с отступом `margin` от меньшей стороны с каждой стороны, по центру; `x_css = ox + x * scale`.
  - `createTemplate(animal, cssW, cssH) -> { clip(ctx): void, drawOutline(ctx): void, scale: number }`. `clip(ctx)` запоминает `ctx.getTransform()`, применяет `translate`/`scale` из `fitTransform`, вызывает `ctx.clip(path)` по объединению `fills` (`Path2D`), возвращает прежний transform (клип остаётся; вызывающий делает `ctx.save()` до и `ctx.restore()` после). `drawOutline(ctx)` рисует `lines` (чёрные, толщина `0.012 * min(cssW, cssH)`, круглые концы/соединения) и `dots` (чёрные круги) в тех же координатах; не меняет состояние `ctx` (внутри `save/restore`).

- [ ] **Step 1: Failing tests (`fitTransform`):** `square canvas: scale = size*(1-2*margin)/100 and offsets equal margin*size`; `wide canvas 200x100 centers horizontally`; `tall canvas keeps proportions (scale from the smaller side)`; `margin 0 fills the smaller side exactly`; `zero-size canvas does not throw and gives scale 0`.
- [ ] **Step 2:** `npm test` — FAIL.
- [ ] **Step 3:** Реализовать `fitTransform` и `createTemplate` (`Path2D`-сборка — только внутри `createTemplate`, чтобы чистая часть работала в Node).
- [ ] **Step 4:** `npm test` — PASS.
- [ ] **Step 5:** Commit `feat: coloring template`.

### Task 3: Редактор в режиме шаблона

**Files:**
- Modify: `canvas.js`

**Interfaces:**
- Consumes: `createTemplate` (Task 2).
- Produces: у объекта `createBoard(...)` появляется `setTemplate(animal|null): Promise<void>` — включает/выключает режим раскраски: сбрасывает холст в белый, рисует контур, пересоздаёт историю; метод `getTemplateId(): string|null`. В режиме шаблона каждый сегмент мазка, точка, ластик рисуются в `ctx.save(); template.clip(ctx); …; ctx.restore()`, затем вызывается `template.drawOutline(ctx)`; штампы игнорируются. `loadImage(blob)` в режиме шаблона после отрисовки картинки перерисовывает контур не нужно (контур уже в PNG), но клип для дальнейших мазков активен. При смене размера шаблон пересоздаётся под новый `cssW/cssH` (после масштабирования содержимого — контур перерисовывается поверх).

- [ ] **Step 1:** Реализовать `setTemplate`/`getTemplateId` и клип+перерисовку контура в `dot`, `drawTo`, `placeStamp` (штамп в шаблоне — no-op), ластике.
- [ ] **Step 2: Ручная проверка в браузере** (временно вызвать `setTemplate(getAnimal('cat'))` из консоли, если нужно, через временный `window.__board`; убрать после проверки): мазок через границу закрашивает только внутреннюю часть; мазок снаружи ничего не оставляет; линия контура не закрашивается мазком; ластик не стирает контур; отмена возвращает краску, контур остаётся одним; смена размера окна пересчитывает контур, краска не искажается.
