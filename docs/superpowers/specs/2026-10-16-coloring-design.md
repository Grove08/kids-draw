# Раскраски животных (этап 3 детской рисовалки) — дизайн

Дата: 2026-10-16. Расширяет `2026-10-16-kids-drawing-pwa-design.md`.

## Цель
Раскраска зверушек для ребёнка 3 лет на iPhone и iPad: контур животного, раскрашивание кистью, краска не выходит за контур.

## Решения (согласованы)
- Раскрашивание кистью, как в рисовалке (цвета, 3 толщины, ластик, отмена).
- Краска видна только внутри зверушки; снаружи холст остаётся чистым.
- Контуры рисуются вручную как векторные кривые, ~8 штук: кот, собака, заяц, медведь, слон, лев, рыба, утка. Крупные округлые формы, толстая линия, без мелочей.
- Раскраска сохраняется в галерею как обычный рисунок; при повторном открытии ограничение краски восстанавливается.

## Экраны
- **Вход:** в галерее кнопка 🖍️ рядом с 🔤 → сетка 8 миниатюр контуров.
- **Раскраска:** тот же редактор, что рисовалка (панель инструментов, 🏠), но поверх рисунка контур зверушки; кнопка штампов скрыта.

## Данные (`animals.js`)
`ANIMALS: Array<{ id: string, name: string, fills: string[], lines: string[], dots: Array<{x,y,r}> }>` в системе координат 0..100 × 0..100 (SVG path data):
- `fills` — замкнутые контуры частей тела; их объединение = область, в которой видна краска.
- `lines` — штрихи контура (обводка частей тела и внутренние линии: рот, усы).
- `dots` — заливаемые чёрные точки (глаза, нос).
`id` — латиницей (`cat`, `dog`, `rabbit`, `bear`, `elephant`, `lion`, `fish`, `duck`).

## Архитектура
- `animals.js` — данные зверушек.
- `template.js` — `createTemplate(animal, cssW, cssH) -> { clip(ctx): void, drawOutline(ctx): void }`: пересчитывает координаты 0..100 в размер холста с отступом 8% и сохранением пропорций, строит `Path2D` из `fills`; `clip(ctx)` вызывает `ctx.clip(path)`; `drawOutline(ctx)` рисует `lines` (чёрная линия толщиной 1.2% от меньшей стороны, круглые концы) и `dots`.
- `canvas.js` — `createBoard` получает метод `setTemplate(animal | null)`: мазки и ластик рисуются внутри `ctx.save(); template.clip(ctx); … ctx.restore()`; после каждого сегмента мазка и после ластика контур перерисовывается; при смене размера шаблон пересчитывается; снимки истории включают контур; штампы в режиме шаблона не используются (кнопка скрыта).
- `coloring.js` — экран выбора: сетка миниатюр (маленький `<canvas>` на каждую зверушку через `template.drawOutline`), нажатие вызывает колбэк `onPick(animal)`.
- `app.js`, `gallery.js`, `index.html`, `style.css` — кнопка 🖍️, экран выбора, запуск редактора в режиме шаблона, скрытие кнопки штампа.
- `storage.js`/`app.js` — запись рисунка получает необязательное поле `template` (id зверушки); при открытии из галереи, если поле есть, включается шаблон.
- `sw.js` — новые файлы в кэш, версия `kids-draw-v3`.

## Поток данных
Выбор зверушки → редактор открывается с `board.setTemplate(animal)`, холст белый, нарисован контур → мазок рисуется внутри клипа → контур перерисовывается → история/автосохранение как у рисовалки, `template: animal.id` сохраняется в записи.

## Ошибки и риски
- Контур не подходит экрану (iPad/альбом): пересчёт по размеру холста с сохранением пропорций.
- Неизвестный `template` в записи (например, зверушку удалили): рисунок открывается как обычный.
- Производительность: перерисовка 3–8 путей после каждого сегмента мазка; на устройстве проверить плавность.
- Отмена после смены размера: история сбрасывается (как у рисовалки), контур остаётся.

## Проверка
- Автотесты: `animals` (8 записей, уникальные id, непустые `fills`/`lines`, числа координат в 0..100), `template` (преобразование координат: центровка, сохранение пропорций, отступ; пустая геометрия не падает), запись с `template` сохраняется и читается.
- В браузере: краска не выходит за контур, контур остаётся поверх, ластик не стирает контур, отмена работает, галерея открывает раскраску с ограничением.
- На iPhone/iPad (вручную): плавность, вид контуров, офлайн.

## Вне объёма
Заливка нажатием, редактор контуров, свои картинки, подсказки цветов.
