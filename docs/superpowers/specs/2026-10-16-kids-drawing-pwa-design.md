# Детская рисовалка (PWA для iPhone) — дизайн

Дата: 2026-10-16

## Цель
Простой графический редактор для ребёнка 3 лет, устанавливаемый на iPhone как PWA. Пользователи: ребёнок, пользуются двое взрослых (автор и жена). Не публичный продукт: без аккаунтов, без сервера, без App Store. Второй этап (отдельная спецификация): обучение азбуке с обводкой букв на том же холсте — вне объёма этого документа.

## Допущения
- Целевые устройства: iPhone и iPad (портрет и альбом). Раскладка адаптивная: панель на iPad крупнее и не растягивается на весь экран; Apple Pencil (pointerType `pen`) работает как палец, ладонь при этом игнорируется.
- Русскоязычный интерфейс не нужен: у ребёнка интерфейс без текста.
- Данные хранятся только на устройстве.
- Раздача: ссылка на GitHub Pages (HTTPS), установка через Safari «Поделиться → На экран "Домой"» на каждый телефон.
- Эмодзи-зверушки используются из системы iOS (без собственных картинок).

## Экраны
**Холст (главный).** Почти весь экран — холст; по краям крупные кнопки только с картинками.
**Галерея.** Сетка миниатюр рисунков; первая ячейка — «новый рисунок»; нажатие на миниатюру открывает рисунок для дорисовки.

## Инструменты на холсте
- Цвета: 8 крупных кружков (красный, оранжевый, жёлтый, зелёный, голубой, синий, фиолетовый, чёрный); допустимо добавить коричневый и розовый, если помещаются. Выбранный обведён.
- Толщина: три точки разного размера (тонкая, средняя, толстая).
- Ластик: одна кнопка, толщина берётся из выбранной.
- Штампы: кнопка открывает ленту ~12 эмодзи-зверушек; выбор зверушки + касание холста ставит её в точке касания. Режим штампа действует, пока не выбрана кисть. Штампы не перетаскиваются и не масштабируются после установки.
- Отмена: одна кнопка, последние ~20 действий.
- Домик: переход в галерею; рисунок сохраняется автоматически.
- Касания большой площадью (ладонь) игнорируются.

## Родительские функции
Скрыты за значком шестерёнки на галерее, открываются удержанием 2 секунды: «Сохранить в Фото» (через системное меню «Поделиться»), «Удалить рисунок».

## Архитектура
Статические файлы без сборки, чистый HTML/CSS/JS:
- `index.html` — каркас, два экрана.
- `style.css` — крупные элементы, safe-area для выреза, запрет выделения текста и «резинового» скролла.
- `app.js` — переключение экранов, панель инструментов.
- `canvas.js` — рисование через Pointer Events, ластик, штампы, стек отмены.
- `storage.js` — IndexedDB: сохранение/чтение рисунков как PNG, запрос постоянного хранилища.
- `sw.js`, `manifest.webmanifest` — офлайн и установка; иконки приложения.

## Поток данных
Касание → `canvas.js` рисует → при отпускании пальца снимок для отмены → через ~2 с после последнего изменения `storage.js` автосохраняет → галерея читает PNG и показывает миниатюры.

## Ошибки и риски
- Хранилище недоступно: приложение работает, предупреждение показывается родителю в родительской зоне, не ребёнку.
- Safari может очищать данные неиспользуемых сайтов; для установленных на «Домой» это обычно не происходит; запрашиваем `navigator.storage.persist()`. Кнопка «Сохранить в Фото» — резервная копия.
- Размер холста масштабируется под плотность экрана с верхним пределом, чтобы не упираться в память.

## Проверка
- Логика (рисование, отмена, сохранение) проверяется в браузере и в мобильной эмуляции.
- Касание пальцем, ладонь, установка на экран «Домой», офлайн и Share-лист проверяются вручную на iPhone пользователем.

## Вне объёма
Раскраски, перетаскиваемые наклейки, облачная синхронизация, азбука, звуки.
